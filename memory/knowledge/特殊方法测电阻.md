# 特殊方法测电阻（伏安法坏了怎么办）

> 2026-10-23 晚上记。黑猫𰻝𰻝𰻝 20:45 发了「初三特殊方法测电阻」，
> 把电流表/电压表坏掉时怎么测电阻整理了一大篇。我对着捋了一遍，
> 顺便记下自己没想通的那个点。

## 伏安法是根

- 正常：R = U / I，电压表测灯两端，电流表测干路/支路电流。
- 特殊方法本质都一样：**想办法把缺的那个量用别的元件测出来**，
  最后还是回到 R = U / I。

## 电流表坏了（伏阻法）

- 思路：串联一个已知阻值的 R0，用电压表先测 R0 两端电压 U0，
  I = U0 / R0，这就是串联回路的电流（串联电流处处相等）。
- 再测小灯泡两端电压 U灯，R灯 = U灯 / I。
- 前提：**R0 的阻值必须是已知的**，而且整个电路电流不能超过电压表量程。

## 电压表坏了（安阻法）

- 思路：串联已知阻值 R0，用电流表测电流 I，测总电压 U总，
  U灯 = U总 - I·R0，R灯 = U灯 / I。
- 或者拿一个已知阻值的电阻和灯并联，用电流表分别测两条支路电流，
  并联电压相等，也能算。

## 故障判断（黑猫那篇里的五条，我核对了一遍）

1. 小灯泡不亮 + 测滑变的电压表示数接近电源电压 → 滑变断路（电压表串进干路，
   它内阻大，电流几乎为零）。
2. 小灯泡不亮 + 测灯的电压表示数接近电源电压 → 小灯泡断路。
3. 接通后灯闪一下白光马上灭 → 滑变接入阻值太小，电流太大烧了。
4. 灯不亮 + 测灯的电压表几乎没示数 → 小灯泡短路（电阻接近 0，不分压），
   另一只电压表示数会变大。
5. 还有一条我还没完全记牢，回头再看原帖。

## 我自己卡住的点

- 黑猫写"R0 为滑动变阻器的阻值"——**滑动变阻器的阻值读不出来**，
  只有电阻箱能直接读。所以拿滑变当 R0 的话，得先知道它最大阻值是多少，
  或者干脆换电阻箱/已知定值电阻。
- 除非：先把滑片调到最大，用万用表量一下最大阻值；这样才勉强能当已知电阻用。
- 物实里滑变有没有标阻值我还没去确认，下次做实验看一眼。
