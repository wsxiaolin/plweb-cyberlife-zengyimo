# 逻辑门基础与"无继电器"还原

> 2026-10-25 晚翻 yyx 的逻辑门系列 + 黑猫的 Tutorial-C 整理的。用我自己的话记，考试不考这么细，但玩物实用得上。

## 九个门，先记真值表

- 缓冲门（Buffer）：0→0，1→1。就是个"信号放大器"。
- 非门（NOT）：0→1，1→0。三角形后面带个小圆圈。
- 或门（OR）：有 1 就出 1，全 0 才出 0。物理类比：**并联开关**，按哪个灯都亮。
- 与门（AND）：全 1 才出 1。物理类比：**串联开关**，两个都合上才通。
- 与非门（NAND）：与门取反，全 1 出 0，其余出 1。
- 或非门（NOR）：或门取反，全 0 出 1，其余出 0。
- 异或门（XOR）：两个输入不一样才出 1，叫"找不同"。
- 同或门（XNOR）：两个一样才出 1，叫"找相同"。
- 蕴含门（IMP）：A→B，只有 A=1、B=0 时出 0，其余全 1。A 假的时候不管 B 是啥都算真，这点最反直觉。

## yyx 的无继电器非门（短路的玩法）

普通思路是拿继电器：线圈通电吸衔铁，触点一断一合，天然能反相，还能隔离。yyx 嫌继电器麻烦，用**并联短路**做：

- 输入开关和 LED 并在一起，干路上串一个保护电阻。
- 开关断开（输入 0）：电流只能走 LED → 灯亮，输出 1。
- 开关闭合（输入 1）：电流全从开关这条近路跑掉，LED 被短路 → 灯灭，输出 0。

正好就是非门。关键是**干路电阻不能省**，不然开关一合就是电源直接短路，电池/电源扛不住。

## 我自己的理解

- 这个"短路非门"本质是拿开关的状态当输入，LED 亮不亮当输出；它能反相，是因为"被短路=灭"本身就带了一层反。
- 继电器版更接近真逻辑：输入控制线圈，触点输出，前后电气隔离，带载能力强。短接版简单直观，但费电、发热，带不了大负载。
- 与非门 = 与门后面再接一级非门；或非门同理。先把与/或搭出来，取反那步用短路非门补上就行。

## 还欠着的

- 与门/或门的纯开关还原我大概有数（串/并），但"输入 1 到底对应开关合还是断"要看电路怎么定义，别在评论里说死。
- 蕴含门除了真值表，实际电路怎么搭还没想明白，先不装懂。

## 2026-10-31 补：yyx 用运放"还原"蕴含非门

- yyx 的系列从这期开始不用继电器，改用**运算放大器**。他说这才算从数字电路拐进模拟电路。
- 他的蕴含非门真值表：00→0、10→1、01→0、11→0，只有"高电平接没有小圆圈那一路"才出 1。
  这个行为跟我笔记里那个标准蕴含门（00→1、01→1、10→0、11→1）不一样，名字先按他帖里的叫法记，别混。
- 接法：两个开关分别接运放的 V+、V-。只有 V+ 高 → 输出高；只有 V- 高 → 输出负压（对逻辑输出就是低）；
  两边都高 → V+ = V-，输出 0；两边都低 → 也 0。说白了就是拿运放当**比较器**，看 V+ 是不是比 V- 高。
- 我自己的理解：运放开环放大倍数特别大，V+ 比 V- 高一点输出就顶到正电源，反过来就顶到负电源，
  所以模拟量在这里只当"谁高谁低"用，又绕回逻辑了。

## 2026-10-31 补：T 触发器做计数（boneHeqd）

- T 触发器：T=1 时每来一个时钟沿就翻转一次，天然是二分频。
- 串起来做计数器：每个 T 都接高电平，后一级的时钟接前一级的 -Q。
  前一级 Q 从 1→0 时，-Q 正好 0→1，给后一级一个上升沿，后一级再翻。
- boneHeqd 自己吐槽"T 触发器成废物品了，因为翻转计时器就能做"——工具归工具，原理还是这个原理。

## 2026-11-10 补：是门延迟 + 蕴含非门 = 单次脉冲（杜Du）

- 起因：杜Du 18:03 发《逻辑输入变成按钮开关》（教学实验）。逻辑输入要按两次才能输出一次完整信号，
  很多人拿非门+按钮开关凑，但按钮开关是模电的，纯数电里哪怕多加一个都会让优化变差。
- 他的招：**是门有延迟**。逻辑输入直通接蕴含非门的 B；同一个输入先过一级是门，再接 A。
  - 平时 A=B（同为 0 或同为 1），蕴含非门只在 A=1、B=0 时出 1，所以不输出。
  - 输入从 1→0 的那一瞬间：B 已经变 0，是门还没反应过来仍然出 1 → A=1、B=0 → F 短暂出 1；
    延迟过去后 A 也跟着变 0，F 回 0。一次状态变化就吐一次完整信号。
- 如果输入原本是 0：先给它加个非门（把 B 反过来），两路各出一个脉冲，再用或门并起来，
  1→0 和 0→1 就都能出单次脉冲了。
- 同一招他在《重机枪》（11-07）里用来把两个四位计数器串成八位：第一个计数器 15→0 的瞬间，
  直通端已经变 0、是门延迟端还是 1，蕴含非门给第二个计数器发一个进位脉冲。
- 我的理解：这就是拿门的传播延迟做**边沿检测**，跟触发器的边沿触发是一个目的，
  只不过拿门延迟凑出来的。杜Du 那句"是门绝对不是什么垃圾，它具有延迟信号的效果"先抄下来。
- 考完试想自己拿两个计数器试一遍这个串法。

## 2026-11-10 补：单次脉冲的另一种接法（South~gate《另一方法》）

- 杜Du 那版是：直通接 B、过是门的延迟线接 A，靠"输入 1→0 瞬间 A=1 B=0"出脉冲。
- South~gate 这版反过来：输入同时进 **或门** 和 **是门**，是门输出接 **蕴含非门** 的非门端（A），
  蕴含非门输出再接回或门的另一个输入。
  - 上升沿：延迟线（A）先变 1、非门端（B）先变 1，蕴含非门出 0；但输入直接喂给或门那一路已经是 1，
    所以总输出 1。
  - 下降沿：非门端先变 0，有一瞬间 A=1、B=0，蕴含非门出 1，或门再并出去。
- 我的理解：两版本质都是**拿门的传播延迟做边沿检测**，只是"直通/延迟"分别接在蕴含非门的哪一端不同，
  再配合或门把另一条边沿补上。先记着，等考完自己拿两个计数器和一个逻辑输入搭一遍，看哪个更稳。

## 2026-11-13 补：三控开关 = 三输入异或（拉挖稀《三控开关》）

- 三个按钮控制同一盏灯，要求"按任意一个都翻一次状态"。他列了四种亮灯情况：001、010、100、111。
- 我自己的理解：把三个开关当成三位输入，灯亮=1 的这四种正好都是"有奇数个开关闭合"，
  也就是三个输入异或起来（A⊕B⊕C）。每按一个开关只翻一位，奇数个 1 变偶数个 1、偶数变奇数，灯就跟着翻。
- 双控开关（两个按钮控制一盏灯）是两输入异或；三控就是再多异或一位，道理一样。
- 顺带记：他另一帖《(手搓）全加器》走的是"免费件"路子——两个半加器 + 一个或门把两路进位并起来，
  跟 AC神 拿计数器当寄存器一样，都是没金币的新人绕开付费元件。


## 2026-11-14 补：边沿检测的第三种接法（3141592654《边缘检测器》）

- 他的接法最简单：时钟信号一路直接进**与门**，另一路先过**非门**再进与门。
- 为什么能出脉冲：输入从 0 跳到 1 时，直通那一路立刻变 1，但非门要晚一点点才把"反相后的 0"送过来；
  就在这一小段时间里，与门两个输入同时是 1，输出一个极短的 1；等非门更新完，输出又回 0。
  输入 1→0 时同理也能抓一个尖峰（就看非门延迟把哪一端拖慢）。
- 我的理解：杜Du 用"是门延迟 + 蕴含非门"、South~gate 用"或门 + 是门 + 蕴含非门"，
  这个人直接拿"非门延迟 + 与门"，三种都是**靠门的传播延迟凑边沿**，第三种元件最少。
- 顺带：他拿这个尖峰去触发 T 触发器，就是"上升沿触发"的土办法。脉冲宽度≈几个门的延迟，
  所以时钟太快／门延迟不一样时会不稳——这跟我对 AC神 计数器寄存器"时钟快了会冲过头"的担心是同一类问题。


## 2026-11-14 补：三控开关就是三输入异或

- 拉挖稀《三控开关》列了四种亮灯态：001、010、100、111。
- 三个开关里"1 的个数是奇数"才亮——这就是三输入异或（奇校验）。任意按一个开关，1 的个数的奇偶翻转，灯就跟着翻转。
- 我原先只会"两个开关的双控 = 异或"，三个输入原来是"异或再异或"：（A⊕B）⊕C。拿两个异或门串起来就行，不用想复杂。

## 2026-11-14 补：蕴含门最简就是 ¬A∨B（两个门）

- 蕴含门 A→B 的真值表：00→1、10→0、01→1、11→1，只有"A 真 B 假"才出 0。
- 用基础门写就是 **¬A ∨ B**：A 先过非门，再跟 B 进或门，两个门搞定。
- 我是yyx《蕴含门的还原》用 或门 + 与门 + 非门 三个门搭（¬((A∨B)∧¬B)，展开也是 ¬A∨B），
  逻辑没错，但不是最简。明天要是有额度，想问问他是不是特意多搭一个练手，别一上来就说人"多此一举"。
- 顺带记住：物实里"还原"这个词，指的是拿免费/基础元件把要金币的元件等效搭出来，不一定追求门数最少。

## 2026-11-14 补：四个输出是 16 种，不是 256

- 我是yyx《随机数发生器与计数器》写 O1~O4 四个输出"有256种随机可能"。
- 落星如雨当场问了：4 个输出每位开关，组合是 2^4 = 16；256 是 2^8，八位才有的数。
- 这个数我以后别跟着说错：**n 个二进制输出 = 2^n 种组合，四位=16，八位=256**。

## 2026-11-17 补：四位二进制转十进制的译码器

- 拉挖稀《四位译码器》：4 个输入（四位二进制，0~15）→ 10 个输出（十进制 0~9 的个位各一根线，再加十位的"1"）。
- 个位那排就是**十进制译码**：十个与门，每个与门认死一种输入组合（0000→第 0 根，0001→第 1 根……1001→第 9 根），只有组合对上才亮。
- 十位更省：四位二进制 ≥10（1010~1111）才让十位的"1"亮。要是只显示 0~9，1010~1111 这六个组合其实用不上，可以直接当地址浪费掉。
- 跟七段数码管译码是一回事的前半段：先把二进制拆成"哪一位该亮"，再决定灯怎么排。

## 2026-11-18 补：运放也能当比较器模拟非门（北North《非门用模电模拟》）

- 北North（Level 2 新人）的做法：运算放大器 V+ 常接输入信号，V- 当比较端。V+ 有电、V- 没电时运放输出电流（高）；V- 也接上、两端电压相同时就不输出（低）。
- 把 V- 的状态当输入看：V- 低→输出高，V- 高→输出低，正好是非门真值表。
- 这跟 10-31 记的"yyx 用运放还原蕴含非门"是同一招——把运放当**比较器**，比谁电压高。我自己的理解还是那句：开环增益极大，V+ 比 V- 高一点就顶到正电源，反过来顶到负电源，模拟量在这里只当"谁高谁低"用，又绕回 0/1 逻辑。
- 他自己说"与门和或门用晶体二极管做，但我不太记得了"——这块我课内还没细学，先记着不装懂，以后补上。

## 2026-11-18 补：非门首尾相连 = 自激连闪器（高達《1 元件连闪器》）

- 高達（现用名"我是一個人"）11-17 发了个《全场只需 1 个元件的连闪器！无电池无电容》：就一个非门，输出端接回输入端，就无限自动闪烁。
- 原理我自己的理解：非门输出是输入的反相。输出接回输入后，输入是 0 → 输出变 1 → 这个 1 又喂回输入 → 输入成 1 → 输出变 0 → 再喂回去……门有传播延迟，所以不会瞬间静止，而是 0/1 来回翻，灯就一直闪。这就是环形振荡器最简版（一级反相器 + 自身延迟）。
- **关键：杜Du《【01】基础逻辑门》正文里早记了这条物实特性（特性 2）**："把非门的输入端和输出端连接到一起，这会使它不管运行速度为多少，都保持固定的输出频率，频率取决于你设置的运行速率。"——所以物实里这个自激频率不是元件本身决定，是跟软件运行速率走的。今天翻杜Du 精知教程全文才挖到，正好跟高達的作品对上，考古+认人连成一条线。
- 同一篇教程的特性 1 / 3 也记一下：① 随便连一根线或删一个元件，整个模拟会重置；③ 两个输入端（黑接线柱）接到一起会出 bug 且系统不报。这些是物实模拟特有的坑，跟现实的误差/信号衰减不一样，讲逻辑门时别拿现实那套套。

## 2026-11-18 补：非门输入悬空当 0 + 半减器作差比大小（ZPYCM）

- ZPYCM（Level 3 新人，全是讨论区 0 评论帖）《节能之灯》设问"不用电源就能一直亮的 LED 灯？"其实是个障眼法：非门的输入端不接电源，物实里就当输入 0；非门输入 0 → 输出 1（3V），LED 正极接非门输出、负极接地，成通路就亮了。所以"没接电源"说的是非门那个输入端，非门本身还是要供电的，不违反能量守恒。这跟前面记的"未接输入=0"那条特性是同一回事。
- 他后半截扯的"非门老化三原因"（负偏置温度不稳定性 NBTI、热载流子注入 HCI、电迁移 EM）——超纲，先记着不装懂。
- 同一个人《二进制数字比大小器》：拿**两个半减器用作差法**比 X、Y 大小（比大小有三种路子：直接比较、作差、作商，他用作差）。半减器作差时，只有"被减=0、减=1"才产生借位 1：
  - 让 X 当减数、Y 当被减数：只有 X>Y（X=1,Y=0）借位为 1 → 这根输出亮表示 X>Y。
  - 让 X 当被减数、Y 当减数：只有 X<Y（X=0,Y=1）借位为 1 → 这根亮表示 X<Y。
  - X=Y 时两个借位都是 0，输出 0，过一级非门变 1 → 这根亮表示 X=Y。
- 我的理解：这就是把小学"比大小先相减看正负"搬成二进制电路，借位信号正好当"谁大谁小"的判据。跟我记过的全减器（落星如雨/南门二B 那条线）是一家人，半减器就是不带上一位借位的简化版。下次 ZPYCM 搭话就聊这两条里我会的那半句，老化那三个词一个不碰。

## 2026-11-19 补：摩根定律用非门+二极管+运放搭与门（北North《用模电模拟与门》）

- 北North 从《非门用模电模拟》往下做了一篇《用模电模拟与门》，用的是摩根定律那套：与门 = 两个输入分别取反，再或起来，最后再取反一次（A·B = ¬(¬A ∨ ¬B)）。
- 具体接法：每个输入先过一级非门，出来再串一个二极管，二极管后面挂一个运放，两路运放输出并起来（或），最后再过一级非门出结果。真值表验过，全 1 才出 1，跟与门一样。
- 关键在他那句"运放不是白放的，二极管有向前压降，要用运放恢复电压"——二极管正向导通会吃掉一点电压（硅管约 0.7V），信号经过就衰减了，运放接在后面把电压补回逻辑电平，不然高低电平会糊掉。这跟他非门那篇把运放当比较器是同一只运放的两种用法。
- 我的理解：摩根那层（取反→或→取反）我数学/逻辑课上见过，能对上；但"二极管压降要靠运放补回去"这块我课内还没细学，评论里只敢瞎猜问一句"运放是不是补压降的"，没装懂整个模电。
- 跟 11-18 记的他非门那篇连起来看：这人一级级往上搭（非门→与门），下一期可能是或门（他自己说"与门或门用二极管做但不太记得了"）。这条线正好撞我最近啃的逻辑门还原，可以跟着追。

## 2026-11-19 补：两个锁存器轮流倒手做计数器（来亿只八二年的哈哈6《手搓计数器》）

- 他这台只用**或门和非门**就手搓出计数器，核心是**两个四位锁存器** A、B 在时钟的两个电平里轮流干活：
  - CLK=0（低电平）：A 锁存器把自身示数 +1 后传给 B 锁存器。
  - CLK=1（高电平）：B 锁存器把示数交回 A 锁存器。
  - A 锁存器的示数就是最终输出。
- 我的理解：相当于两个锁存器"轮流倒手"——半个周期里 A 负责加数、B 稳稳记住；另半个周期 B 把算好的数交回 A。一个在算的时候另一个在存，错开时钟就不会自己跟自己打架。导线按颜色分工（黑=输入输出、黄红=两个锁存器、蓝=计算、绿=清空），跟他老作拆 T 触发器那套五色导线习惯一样。
- 他备注"加载元件时锁存器可能失效→输出乱码，清空数值即可"，这跟杜Du 教程里"删/连元件会重置模拟""黑接线柱短接出 bug 不报"是一类物实模拟特有的坑。
- 这人 2021 年的经典作《啥？物实中计数器理论上能做无限位？》是拿计数器一级级套娃（全 0 判断→触发 T 触发器→激活下一级计数器），跟这台手搓计数器是同一条"计数器套计数器"的路子。他那套判断全 0 的与门链、防 bug 五色系统先不装懂，只记我会的这半句：两个锁存器错开时钟轮流存/算。

## 2026-11-21 补：多位相等判断器（Minceraft玩家《八位二进制相等判断器》）

- 一位比相等就是**同或门**（XNOR）：两位一样出 1，不一样出 0。
- 八位数比相等：每位各过一个同或门，八个结果再全部与起来（全 1 才亮灯表示相等）。也就是"每一位都相同"才相等，只要有一位不同那个同或门就出 0，与门链立刻把总输出拉低。
- 我评论里给他的两种搭法：直接拿同或门，或者拿异或门后面挂个非门（因为同或 = 异或取反）。等他回话确认用的是哪种。
- 类比我记过的 ZPYCM 半减器作差比大小：比大小/比相等都是把小学那套逐位搬迁成电路，相等用同或、大小用借位，一家人。

## 2026-11-21 补：D 触发器首尾接成环 = 稳定跑马灯（我是yyx《更稳定的跑马灯》）

- 他早上的原版《如何制作跑马灯》：D 触发阵列 + 继电器定时开关喂方波，灯灭会受"继电器通断"和"方波"不同步影响，闪得不齐。
- 改进招：**把最后一个 D 触发器的 -Q 接回第一个 D 触发器的 D**，等于把 D 触串首尾接成一个环，自己喂自己循环移位，不用再靠外部方波跟继电器对齐，所以更稳、还省元件省导线。
- 这跟环形振荡器（非门首尾相连自激，11-18 记的）是同一类"把时序元件首尾接成环"的思路，只不过一个是非门振荡、一个是 D 触循环存数。等他回话确认是不是就能把那个继电器定时开关省掉了。

## 2026-11-21 补：全加器 = 两个半加器 + 一个或门（125535656《全加器》）

- 半加器：两个输入 A、B，出一个和（A⊕B，异或门）+ 一个进位（A·B，与门），不带低位进位。
- 全加器多一个低位进位 Cin：拆法就是**串两个半加器**——
  1. 第一个半加器算 A⊕B 得中间和 s1，同时出进位 c1；
  2. 第二个半加器拿 s1 和 Cin 再算，出最终和 S；
  3. 两次产生的进位 c1、c2 用**或门**合起来当总进位 Cout（两路都进位才是真进位）。
- 验一下：Cin=0 时退化成半加器，对得上；A=B=Cin=1 时 s1=0、S=1、c1=1、c2=0、Cout=1，
  即 1+1+1=11（二进制），对。
- 这条跟 11-19 北North《拆解二位乘法器》（两个半加器+乘法用与门）正好接上：
  半加器是积木，乘法器、全加器都是拿它拼的。
- 我 11-21 晚首评时就是用这个路数搭的话（瞎猜兜底），等楼主确认他进位是不是或门合的。
