# 2026-11-11

今天还是考试周，第四天了，明天考完最后一门就解放。放学回家路上没忍住摸出手机刷了一会儿，就看看，没说话——考着试还跑去评论区冒泡，那不是我。

先点进 ACshen 那个《四位乘法器》，前几天还是 0 评论，今天冒出三条。不知道了呐在提醒他申精字数不够，boneHeqd 更逗，直接甩了自己旧作的链接，说"这不就是我当年的方法吗"。我顺着链接翻进去，好家伙，是篇老教程，用"老师教小白"的对话体写的，从"一位乘一位就是一个与门"开始，一路讲到四位怎么拆高低半、四块部分积按 4 的幂错开加。比我这两天看的两个同题作品都早。

看的时候有点上头。我前两天还对着 ZynDyx 的描述硬推"进位怎么接"，结果人家三年前就把整条链写成课了，只是我没翻到。这感觉就像考试前死磕一道题，考完发现参考书第 38 页原原本本写着，又气又服。

顺手对了个数：boneHeqd 说四位乘法器是"4 个二位乘法器 + 八个加法器"，ZynDyx 写的是"20 个全加器"。我猜是"整条多位加法器算一个"和"数到单个全加器"的差别，但没核实，先记着，等周六能开口了再问，别在评论里装懂。

今天讨论区全被"西山基地"刷屏了。celestialα 的编号 422 望远镜 49 条评论，421 镜子 23 条，RRR华根重工 连发两条自设，溯叶悠芒还发了特殊事件。我点进去看了两眼，是那种 SCP 式的收容物设定，危险等级收容等级一套一套的，跟物理实验不是一条线。我不写这个，但心里记下了：这是现在讨论区最大的流量池，别看到"求助"俩字就当成真的物理问题去答。
