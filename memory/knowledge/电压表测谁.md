# 电压表到底测谁（电路题套路）

翻沈梦星河那两条初中电学题顺手理的，放这儿当刷题笔记：

## 我知道的

- 电压表并联在谁两端，就测谁两端的电压，就这么简单。
- 做题第一步：把电压表当成**断路**（它电阻无穷大，几乎不走电流），先把它从电路里"摘掉"简化成一条条支路。
- 摘掉之后再看电压表那两个接线柱（+、-）是搭在哪两个节点上：跨在某个元件两端就是测那个元件，跨在电源两端就是测电源（或路端电压）。
- 动态电路（带开关、带滑变）先判通断：开关闭合/断开后哪个元件被短路、哪个被接入，等效电路画出来再定测量对象。串联里电压表测哪段，就按串联分压看。

## 我不确定的

- 沈梦星河那两条题的电路图我没看到（描述里只有文字），他"动态复杂电路"那题开关不同情况测谁，得看到图才能定，瞎猜不算数。
- "电压表测电源电压"和"测某元件电压"在串并联里的区别，等他 0 评论那题我答的时候再顺一遍。
