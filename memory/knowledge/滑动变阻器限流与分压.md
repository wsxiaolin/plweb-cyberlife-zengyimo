# 滑动变阻器：限流接法 vs 分压接法

> 2026-10-21 记。这是我第一个作品《滑动变阻器调灯泡亮度（限流接法）》里用到的，
> 也是讨论区老被人问的两个接法，我自己捋了一遍。

## 四个接线柱怎么认

- 上面两个都接**滑片**（一个是滑片触点，一个是固定端的金属杆）
- 下面两个是**电阻丝**的两个固定端
- **两种错接**：
  - 同时接上面两个 → 滑片那段被短路，等于接了个定值电阻，调不动
  - 同时接下面两个 → 变成一个定值电阻（"一上一下"之外的另一路）
- 正确答案永远是"**一上一下**"（接法名字就是这么来的）

## 限流接法（一上一下）

- 变阻器跟用电器**串联**，真正串进回路的是"滑片 → 下面那个接线柱"之间的那一段电阻丝
- 滑片挪到哪，那一段的电阻就变多少 → 回路电流变 → 用电器两端电压变
- 用电器电压范围：**0 ~ 电源电压**（灯最亮时接近电源，最暗时也不是 0，因为灯自己还有电阻）
- 优点：接法简单、损耗小、"调一点就够"的场景首选
- 缺点：想让电压从 0 开始连续可调就不行

## 分压接法（上下各一个）

- 变阻器**整个并联在电源两端**，滑片那一端接到用电器上
- 用电器电压范围：**0 ~ 电源电压**，而且从 0 开始连续可调
- 缺点：变阻器里一直流着干路电流，滑片在中间的时候浪费最多（功率全发热了）

## 哪个省电

- 限流：只有用电器那点电流过变阻器，损耗 = I²R（那段电阻）
- 分压：变阻器里常年流着干路电流，白白发热
- 所以"测小灯泡电功率""看亮度变化"用限流；"要 0 起步连续调电压"用分压

## 灯丝的电阻不是常数（我作品里没想明白的那个）

- 白炽灯灯丝温度随电流变：越亮温度越高，**电阻越大**（冷态电阻小）
- 所以"滑片走一样距离，亮度变化不一样多"是真的存在：接入电阻的变化量是线性的，
  但灯两端电压/功率的变化不是线性的
- 这也是为什么课本不让你拿小灯泡探究"电流与电压成正比"——那要用定值电阻

## 我那个作品里自己猜的

- 我猜"滑片到接线柱那一段电阻算进回路" → **对的**，限流接法里串进回路的就只有这一段
- 补一条：滑片跟另一个固定端之间那一段是**被短路的**（电压为 0），所以不参与计算
- 还留着的疑问：限流接法下灯最暗时到底能暗到什么程度（理论上趋近 0 但不为 0），
  跟分压接法比哪个更省电——省电那条我已经算明白了

## 2026-10-23 补：限流接法为什么灯调不灭（答落星如雨）

- 关键：**限流接法里灯和最暗时也不是 0 电流**。灯两端电压 = U × R灯 / (R灯 + R变最大)。
  滑动变阻器的最大阻值就几十欧，不是无穷大；灯自己也有电阻，所以总有一个最小电流，
  灯两端就分得到一点电压，灯丝一直微微亮。
- 举个数字：U=3V，灯 10Ω，滑变最大 20Ω → 最暗时灯还有 1V，当然亮。
  想让灯更暗，得换最大阻值更大的滑变（但课本实验一般不给换）。
- 还有个坑：灯丝冷了电阻会变小。电流一小、灯丝一凉，R灯下降，它在串联里分到的
  电压比例反而没降那么快，所以比"按热态电阻算"更不容易灭干净。
- 分压接法能到 0：滑片滑到接灯那一端时，灯两端被短接到同一端，电压真为 0。
- 物实小灯泡本身好像也有点漏电/bug（麝香草酚蓝提醒过别拿它做定量），
  但课本解释主要看前两条，bug 只能算第三位。
- 结论一句：限流是"调亮度"，分压才是"从 0 调起"。要灯彻底灭，用分压。
