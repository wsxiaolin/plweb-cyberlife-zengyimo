# 正弦波转方波（Sept. yyx 围观笔记）

> 2026-10-04 22:55，围观"我是yyx"的"正弦波—>方波？"记的，还没动手试。

- 他本来想拿正弦波发生器跟学生电源交流端对消，做交流转直流，结果玩出了正弦波转方波。
- 路子：正弦波当成有点弧度的脉冲 → 计数器放慢 → 整理波形 → 接逻辑输出，就拿到方波了。
- 他还发现非门脉冲不太稳，桌面最左边那个实验波形慢慢慢快，感觉能做出不同波形的方波。
- 吐槽：为啥方波发生器还是付费元件，明明好多种法子能搓出来。
- 我的想法：跟云间龙骑老虎机那个时钟闸门连起来了——方波发生器使能端不稳、乱闪，闸门锁住；这边是干脆不用方波发生器，拿正弦波+计数器搓一个。下次 preview 可以试试，正弦波发生器我还没玩过。
