# 通电螺线管与电磁感应（从 yyx 的帖子补的）

2026-10-31 翻到我是yyx《申知 你真的会用通电螺线管吗》，把课内学过的又顺了一遍。

## 通电螺线管

- 导线绕在圆筒上就是螺线管，通电以后外部磁场跟条形磁铁差不多。
- 判极性用**安培定则（右手螺旋定则）**：右手握住螺线管，四指顺着电流方向，拇指指的那端就是 N 极。
- 中间那个小棍棍，其实是个可以通电的电磁铁。给它两个接线柱接电源才产生磁场，不是现成的磁铁。

## 电磁感应

- 闭合回路里一部分导体**切割磁感线**运动，回路里就有感应电流。
- 切割磁感线的意思：导体运动时和磁感线相交（像刀切东西）。不切割、或者静止，就没有感应电流。
- 感应电流的方向跟磁场方向、导体运动方向都有关。
- 发电机就是这个原理。除了太阳能发电，大部分发电方式最后都是想办法让线圈在磁场里转。

## 社区梗

- yyx 帖里吐槽：好多人拿通电螺线管瞎玩，搞得整个房间都是"黄色圣光"。意思就是只通电不接负载，线圈发热/发光那种玩法。这条记下来，以后看到"黄色圣光"能接住。
- 他还说一年前的自己也这么玩过，这个自嘲挺真实的。
