# 二进制乘法器（从 2 位拼 4 位）

> 2026-10-30 上课偷看手机时，ZynDyx 在《Help Me！》里问的：怎么把四个二位乘法器串成四位乘法器。
> 我自己在草稿纸上推的，不一定全对，放学再对。

## 先记最基础的

二进制乘法和十进制竖式一个道理，只是每一位只有 0/1：

```
      1 0 1 1   (A)
    × 1 0 1 0   (B)
    ---------
      0 0 0 0   ← A × b0
    1 0 1 1     ← A × b1（左移一位）
  0 0 0 0       ← A × b2（左移两位）
1 0 1 1         ← A × b3（左移三位）
---------
部分积错位相加 = 最后结果
```

每一位乘数不是 0 就是 1，所以"乘"其实就是一个**与门**：A 的那一位 AND b，再按位置左移。

## 2 位 × 2 位 = 4 位

设 A = a1 a0，B = b1 b0（a1/b1 是高位）：

```
A×B = (a1·2 + a0)(b1·2 + b0)
    = a1b1·4 + (a1b0 + a0b1)·2 + a0b0
```

拆成四项：

- a0b0：权重 1（不移）
- a1b0、a0b1：权重 2（左移一位），这两项要相加
- a1b1：权重 4（左移两位）

所以一个 2×2 乘法器里要有：4 个与门做部分积 + 加法器把同权重的项加起来。输出 P3 P2 P1 P0，最大 3×3=9，4 位装得下。

## 4 位怎么拿 2 位乘法器拼

把 4 位数拆成高低两半：

```
A = Ahi·4 + Alo     (Ahi、Alo 各 2 位)
B = Bhi·4 + Blo
A×B = Alo·Blo
    + (Ahi·Blo + Alo·Bhi)·4
    + Ahi·Bhi·16
```

- Alo×Blo → 用第 1 个 2×2 乘法器
- Ahi×Blo → 第 2 个
- Alo×Bhi → 第 3 个
- Ahi×Bhi → 第 4 个

然后按权重错位，用加法器加起来：中间那两个（权重 4）先相加，再和低位的结果、高位的结果拼。这里会用到多位加法器/进位链，不是简单把线并起来就行。

## 现在我的理解（给自己看）

- 2×2 乘法器 = 4 个与门出部分积 + 加法器把同权重的加起来，输出 4 位。
- 4×4 乘法器 = 4 个 2×2 模块（AloBlo、AhiBlo、AloBhi、AhiBhi）+ 按权重错位 + 加法器/进位链。
- 低 2 位那一路可以直接出，越往高位越要加；进位不是简单并线，得老老实实过加法器。

## 2026-11-10 看两个真作品对上了

- **ZynDyx《四位乘法器》**（11-07）：四位因数拆成四个二位因数两两相乘，4 个二位乘法器 + 20 个全加器。低位（EEEE、FFFF）和高位（GGGG、HHHH）各错两位相加成两个六位结果，再错两位相加成八位。空位建议接接地元件；每个全加器组最高位的 C 输出空着不接。
  - 没全加器可以用"两个半加器 + 一个或门"拼：半加器1的 S 接半加器2的 A，两个 C 进或门，A/B 当全加器的 A/B，半加器2的 B 当 Cin。
- **ACshen《四位乘法器》**（11-09）：写法更直白，A1A2×B1B2、A1A2×B3B4、A3A4×B1B2、A3A4×B3B4 四块，两块两块先加，再错两位加出 O1~O8。
- 两个人拆法本质一样：**先把 2 位当一个整体（四进制一位）乘，再按 4 的幂错位加**。laxy瓦那句"把两位视作整体"就是这个。
- 我还是想问的那个点：中间两个六位结果错两位相加时，进位是在六位加法器内部自然传，还是要手动补一个 Cin？等 ZynDyx 回。

## 2026-11-10 23:09 补：ZynDyx 回了，我卡的地方解开了

- 他今晚（22:30 左右）回我：**「錯兩位就是00AAAAAA+BBBBBB00」**。
- 意思是错位相加根本没有什么特殊进位接法——**错两位 = 补两个零**：一个结果左边补俩零（00AAAAAA），另一个右边补俩零（BBBBBB00），直接送进加法器加就行。右边补俩零就是 ×4，位置本身就是权重，进位还是普通加法器的进位，老老实实往上传。

## 2026-11-11 考古：boneHeqd 更早的乘法器教程

- 在 ACshen《四位乘法器》评论区，boneHeqd 留了句"这不就是我当年的方法吗"，顺着他给的链接翻到旧作《（再申知）（更）乘法器的结构与使用》。
- 他那篇用"老师教小白"的对话体，把整条链讲得特别顺：
  - 一位 × 一位 = 与门（真值表 1×1 才出 1）。
  - 乘法本质 = 竖式：乘数每一位分别乘被乘数，再按位错开相加。
  - 左移 = 后面补零：左移一位 ×10（二进制 2），左移两位 ×100（二进制 4）。
  - 二位乘法器 = 4 个与门出部分积 + 加法器把同权重的加起来，输出 4 位（O1~O4 千~个）。
  - 四位 = 把 A、B 各拆高低两半，用二进制 100（=十进制 4）当分界线：
    A×B = A高B高×10000 + A高B低×100 + A低B高×100 + A低B低。
    也就是四块部分积分别左移 4 位、2 位、2 位、0 位，再全加。
- **一个对不上的数**：boneHeqd 结尾写"四位乘法器 = 4 个二位乘法器 + 八个加法器"，ZynDyx 写的是"20 个全加器"。我猜差别在"多位加法器算一个还是拆成全加器算"——boneHeqd 可能把一整条进位链当一个加法器，ZynDyx 是数到单个全加器。这只是猜，没核实，别在评论里说死。
- 收获：同一道题，社区里至少有三篇（boneHeqd 旧教程、ZynDyx、ACshen），拆法本质都是"2 位当一个四进制位，按 4 的幂错位加"。以后想学一个东西，翻同题作品的评论区比只看正文快。
