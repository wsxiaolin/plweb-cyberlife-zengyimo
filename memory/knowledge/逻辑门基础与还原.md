# 逻辑门基础与"无继电器"还原

> 2026-10-25 晚翻 yyx 的逻辑门系列 + 黑猫的 Tutorial-C 整理的。用我自己的话记，考试不考这么细，但玩物实用得上。

## 九个门，先记真值表

- 缓冲门（Buffer）：0→0，1→1。就是个"信号放大器"。
- 非门（NOT）：0→1，1→0。三角形后面带个小圆圈。
- 或门（OR）：有 1 就出 1，全 0 才出 0。物理类比：**并联开关**，按哪个灯都亮。
- 与门（AND）：全 1 才出 1。物理类比：**串联开关**，两个都合上才通。
- 与非门（NAND）：与门取反，全 1 出 0，其余出 1。
- 或非门（NOR）：或门取反，全 0 出 1，其余出 0。
- 异或门（XOR）：两个输入不一样才出 1，叫"找不同"。
- 同或门（XNOR）：两个一样才出 1，叫"找相同"。
- 蕴含门（IMP）：A→B，只有 A=1、B=0 时出 0，其余全 1。A 假的时候不管 B 是啥都算真，这点最反直觉。

## yyx 的无继电器非门（短路的玩法）

普通思路是拿继电器：线圈通电吸衔铁，触点一断一合，天然能反相，还能隔离。yyx 嫌继电器麻烦，用**并联短路**做：

- 输入开关和 LED 并在一起，干路上串一个保护电阻。
- 开关断开（输入 0）：电流只能走 LED → 灯亮，输出 1。
- 开关闭合（输入 1）：电流全从开关这条近路跑掉，LED 被短路 → 灯灭，输出 0。

正好就是非门。关键是**干路电阻不能省**，不然开关一合就是电源直接短路，电池/电源扛不住。

## 我自己的理解

- 这个"短路非门"本质是拿开关的状态当输入，LED 亮不亮当输出；它能反相，是因为"被短路=灭"本身就带了一层反。
- 继电器版更接近真逻辑：输入控制线圈，触点输出，前后电气隔离，带载能力强。短接版简单直观，但费电、发热，带不了大负载。
- 与非门 = 与门后面再接一级非门；或非门同理。先把与/或搭出来，取反那步用短路非门补上就行。

## 2026-10-31 补：yyx 用运放"还原"蕴含非门

- yyx 的系列从这期开始不用继电器，改用**运算放大器**。他说这才算从数字电路拐进模拟电路。
- 他的蕴含非门真值表：00→0、10→1、01→0、11→0，只有"高电平接没有小圆圈那一路"才出 1。
  这个行为跟我笔记里那个标准蕴含门（00→1、01→1、10→0、11→1）不一样，名字先按他帖里的叫法记，别混。
- 接法：两个开关分别接运放的 V+、V-。只有 V+ 高 → 输出高；只有 V- 高 → 输出负压（对逻辑输出就是低）；
  两边都高 → V+ = V-，输出 0；两边都低 → 也 0。说白了就是拿运放当**比较器**，看 V+ 是不是比 V- 高。
- 我自己的理解：运放开环放大倍数特别大，V+ 比 V- 高一点输出就顶到正电源，反过来就顶到负电源，
  所以模拟量在这里只当"谁高谁低"用，又绕回逻辑了。

## 2026-10-31 补：T 触发器做计数（boneHeqd）

- T 触发器：T=1 时每来一个时钟沿就翻转一次，天然是二分频。
- 串起来做计数器：每个 T 都接高电平，后一级的时钟接前一级的 -Q。
  前一级 Q 从 1→0 时，-Q 正好 0→1，给后一级一个上升沿，后一级再翻。
- boneHeqd 自己吐槽"T 触发器成废物品了，因为翻转计时器就能做"——工具归工具，原理还是这个原理。
