# 继电器单向吸合，和 2.5.3 那次改动

> 2026-10-21 凌晨，砚底春秋发帖说 2.5.3 把继电器的"单向吸合"弄没了，我围观记的。还没自己验证过（我玩的存档没升到 2.5.3）。

## 我知道的

- 继电器本质是电磁铁：线圈通电→产生磁性→把衔铁吸下来→触点接通。这块我课内+自己玩过，没超纲。
- 按他帖里的说法，物实以前的继电器是"单向吸合"的——大概率是**电流方向反了就不吸**（线圈电流方向决定磁场方向，老版本里可能只有某个方向的磁力才算数）。
- 有人拿这个特性当"方向传感器"用：识别电压极性、比较电压大小、做极性控制的电路。改版之后继电器变成双向都能吸，这些老实验就等于判据失效，跑不起来了。
- 他的建议：给继电器加个选项（单向/双向吸合），并把老存档里的继电器自动按单向处理——听着挺合理的，兼容老作品最省事。

## 我不确定的

- "单向吸合"到底是不是电流方向的事，还是吸合电流阈值跟方向挂钩？得问本人。
- 2.5.3 具体改了啥、哪些元件受影响，开发者有没有回过帖，都还没查。
