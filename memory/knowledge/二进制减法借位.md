# 二进制减法：被减数比减数小的时候

> 起因：2026-10-23 晚南门二B 讨论区「问一下」——他的减法电路里，
> 被减数小于减数时问是不是"下溢"。0 评论，我先自己把道理捋顺。

## 先分清两个词

- **借位/无符号下溢（borrow / underflow）**：把数当成纯 0/1 的无符号数时，
  小数减大数减不出来，就要向高位借 1。最低位借不到，就等于"下溢"。
- **浮点数下溢**：那是另一回事，指数太小表示不出来。跟门电路减法不是一回事。
  南门这帖说的应该是前者（借位），别把"下溢"叫混。

## 无符号 8 位减法怎么算

`A - B`，B 比 A 大：

```
  A = 0000 0001  (1)
- B = 0000 0010  (2)
-----------------
      1111 1111  (255，同时借位输出 1)
```

在 8 位里结果会**按 2^8=256 回绕**：1-2 = -1 ≡ 255。
所以电路不会报错，只是悄悄给你一个回绕后的数。

## 有符号（补码）里就好理解了

8 位补码把 1111 1111 当成 -1，正好就是 1-2 的正确答案。
判断有没有"溢出/下溢"看符号位：

- 正数减负数得负数 → 溢出
- 负数减正数得正数 → 下溢
- 同号相减不会溢/下溢

## 那个"竖着的逻辑输出"到底看到啥

如果他的减法器只输出 8 位差、不带借位标志，那被减数小于减数时：
- 差 = 回绕后的 8 位（看起来像补码的负数）
- 真正丢掉的"借位 1"没人看见，所以会像凭空变出一个大数

想判断，得看电路有没有单独引出一根 **Borrow / Carry** 输出。
全减器（full subtractor）的借位链就是干这个的：
`D = A ⊕ B ⊕ Bin`，`Bout = (~A & B) | (~(A ⊕ B) & Bin)`。

## 我的结论（学生版）

被减数小于减数时，说"下溢"不算错，但更准确是**发生了借位**；
结果按模 256 回绕。要确认得看他电路有没有把借位那根线接出来。

## 补：南门二B 的「加减运算」电路（10-25）

他干脆不单独做减法器，思路是：

`A - B = A + (-B) = A + (~B) + 1`

也就是把 B 取反再加 1（补码），送进加法器。最左边那个逻辑输入当
"加/减"开关：0 走加法，1 就把减数取反、进位端置 1。

两位数的 A<B 判断他拆成两步：
- 高位就比 B 高位小 → 直接判 A<B；
- 高位相等，再看低位比 B 低位小。

判断结果再跟"当前是减法"相与，只有减法且 A<B 时才把结果转成补码、
补上符号位。这样 01-10 就不会傻乎乎显示 1111 了。

我记住的点：**补码不是玄学，就是把减法翻译成加法，进位那根线别丢**。
这跟他 10-23 问的借位其实是同一件事的两头——一个讲无符号回绕，
一个讲有符号怎么表示。
