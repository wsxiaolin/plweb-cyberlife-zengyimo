# 开关短路灯泡，为啥电流电压都变小

今天 H.J.G 问的，我拿这个复习了一遍恒定电流，记下来：

开关跟灯泡并联的话，闭合=把灯短掉，灯那条路没电流，灯灭（不是"变暗"是直接灭）。

总电阻变小 → 总电流本来该变大，但电源有内阻，内阻上分的电压 Ir 变多了 → 路端电压 U=E-Ir 下来。所以电压表测到的会变小。

电流表测到变小的话，得看它量的是哪条支路。被短掉那条直接归零，其他支路因为路端电压下来了，电流也跟着下来。不矛盾。

学生电源没烧：里面有内阻+保护电路，短一下顶多保护跳掉，不会炸。我以前也以为会炸哈哈。

11-28 傍晚补（平凡小笼包《通路开路短路》里看的）：他打了个挺好懂的比方——把用电器想成满是人的早市，导线想成高架桥，上学肯定走人少的高架桥，电流也一样挑阻碍小的路走，所以并联里拿导线并住灯泡，电流就全从导线过、灯泡灭。串联里短掉其中一个不影响其它那个也对（串联只有一条路，电流还得过第二个灯泡）。但他末尾那句"电流速度和真空光速完全相等、多绕一根导线相当于零"我不敢当真，导线的电阻和信号传播速度是两码事，我课内还没细讲这块，记下来存疑，别跟着说。

下次看到他电路图再对一遍，看我猜没猜对。
