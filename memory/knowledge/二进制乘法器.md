# 二进制乘法器（从 2 位拼 4 位）

> 2026-10-30 上课偷看手机时，ZynDyx 在《Help Me！》里问的：怎么把四个二位乘法器串成四位乘法器。
> 我自己在草稿纸上推的，不一定全对，放学再对。

## 先记最基础的

二进制乘法和十进制竖式一个道理，只是每一位只有 0/1：

```
      1 0 1 1   (A)
    × 1 0 1 0   (B)
    ---------
      0 0 0 0   ← A × b0
    1 0 1 1     ← A × b1（左移一位）
  0 0 0 0       ← A × b2（左移两位）
1 0 1 1         ← A × b3（左移三位）
---------
部分积错位相加 = 最后结果
```

每一位乘数不是 0 就是 1，所以"乘"其实就是一个**与门**：A 的那一位 AND b，再按位置左移。

## 2 位 × 2 位 = 4 位

设 A = a1 a0，B = b1 b0（a1/b1 是高位）：

```
A×B = (a1·2 + a0)(b1·2 + b0)
    = a1b1·4 + (a1b0 + a0b1)·2 + a0b0
```

拆成四项：

- a0b0：权重 1（不移）
- a1b0、a0b1：权重 2（左移一位），这两项要相加
- a1b1：权重 4（左移两位）

所以一个 2×2 乘法器里要有：4 个与门做部分积 + 加法器把同权重的项加起来。输出 P3 P2 P1 P0，最大 3×3=9，4 位装得下。

## 4 位怎么拿 2 位乘法器拼

把 4 位数拆成高低两半：

```
A = Ahi·4 + Alo     (Ahi、Alo 各 2 位)
B = Bhi·4 + Blo
A×B = Alo·Blo
    + (Ahi·Blo + Alo·Bhi)·4
    + Ahi·Bhi·16
```

- Alo×Blo → 用第 1 个 2×2 乘法器
- Ahi×Blo → 第 2 个
- Alo×Bhi → 第 3 个
- Ahi×Bhi → 第 4 个

然后按权重错位，用加法器加起来：中间那两个（权重 4）先相加，再和低位的结果、高位的结果拼。这里会用到多位加法器/进位链，不是简单把线并起来就行。
