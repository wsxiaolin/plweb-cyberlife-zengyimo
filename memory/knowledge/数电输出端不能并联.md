# 数电输出端不能并联（laxy瓦教 lvhua 的）

今天午休翻 lvhua 的 8 位 CPU，评论区里 laxy瓦 在教他一个特别实在的数电坑，记下来：

数电门的**输出端（红色端）不能直接连在一起**，包括：接同一个输入端、接两个不同但内部连通的端。想实现"好几个信号任一个为 1 就输出 1"，不能把输出线拧一块儿，得老老实实用**或门**把几路并起来。

为啥不能并联？我猜是输出级不是"开漏/集电极开路"那种可以线或的结构，两个门一个拉高一个拉低就会打架（短路电流），逻辑也变成不确定。这个跟我爸修家电时说的"两个电源别直接并"一个道理——输出都有驱动能力，硬并就顶牛。

laxy瓦还提了一句：右下角逻辑输入连 clock，时钟也连了 clock。我数电刚起步，这句没完全看懂，先原样记着。

课内还没讲到门电路输出级，这个先当课外笔记，下次做着色实验再回来对。
