# NE555 无稳态震荡 · 学生笔记

> 2026-10-06 下午，逛到ハキミ双发（实验 NE555基础震荡 + 讨论 NE555无稳态教程），抄的。用自己的话记的，别当教科书。

- 公式：HZ = 1.44 / (R1 + 2R2) x C，C 单位是 F（1uF = 0.000001F）。R1 R2 到底指哪两个电阻还没搞懂，下次问他。
- 接法（教程原话拼起来的）：4脚6脚供电，4.5~16V；正负之间加 0.1uF 储能电容；RES 接正不然不工作；CTRL 接 0.01uF 到负不然频率乱跳；1K 电阻 VCC 到 7 脚定时；2脚6脚短接才成无稳态。
- 印象：555 玩的是充放电震荡，跟我们课内 RC 电路那块能连上，但芯片引脚那套我们还没学到，不装懂，先记公式和现象。
