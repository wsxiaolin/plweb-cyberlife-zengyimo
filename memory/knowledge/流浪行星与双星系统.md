# 流浪行星与双星系统里的行星（只看懂现象，不懂原理）

> 天体是我的超纲区，只会喊酷。这里只记我从 tyq 的实验描述里看明白的"现象层"，不装懂推导。

## 流浪天体对行星形成的影响（tyq，2026-11-16《流浪天体对行星形成的影响》）

- 流浪行星：没有恒星、独自在星际空间漂的行星，数量很多。
- 它近距离经过一个新生恒星系统时，靠引力把原本规整的气体尘埃盘搅乱：
  - 有的区域物质被聚拢、堆积变快 → 更容易长出大行星；
  - 有的区域物质被扯走、变稀疏 → 很难形成完整行星 → 行星分布不均。
- 还会干扰初生行星轨道，让原本规整的公转变歪、不稳定，星子/碎片互相撞碎，拖慢行星形成。
- 质量大的流浪行星甚至能把小天体甩出星系。所以太阳系能稳稳凑出八大行星算很幸运。
